# 守夜人桌遊社網站操作手冊

歡迎來到守夜人桌遊社網站！

本網站提供社團資訊、活動文章、電子報、社員論壇、留言互動、按讚、社員 ID、等級經驗值等功能。
本手冊將介紹一般社員可以使用的功能與操作方式。

---

## 一、登入網站

進入網站後，若尚未登入，系統會自動引導至登入頁面。

請使用社團提供的帳號登入。

登入後，才可以使用以下功能：

* 瀏覽社員論壇
* 撰寫社員論壇文章
* 送出文章審核
* 留言
* 編輯自己的留言
* 刪除自己的留言
* 按讚文章
* 按讚留言
* 查看社員 ID
* 查看等級與經驗值
* 查看自己的貼文

---

## 二、社員 ID

登入後，網站左側會顯示你的社員 ID。

社員 ID 會出現在：

* 文章作者名稱
* 留言作者名稱
* 會員資訊區
* 等級資訊區

如果是第一次登入，系統可能會要求你設定社員 ID。

### 更改社員 ID

若想修改社員 ID，可在左側會員資訊區點選「更改ID」。

操作方式：

1. 點選左側會員資訊中的「更改ID」
2. 輸入新的社員 ID
3. 點選儲存
4. 儲存成功後，新的社員 ID 會顯示在網站上

建議使用大家容易辨識的暱稱。

---

## 三、查看等級與經驗值

登入後，左側會員資訊會顯示你的等級與經驗值。

你可以看到：

* 目前等級
* 目前經驗值
* 升到下一級所需經驗值
* 總經驗值
* 經驗值來源

經驗值會依據你在社員論壇中的互動自動計算。

---

## 四、經驗值取得方式

目前經驗值主要來自社員論壇文章與互動。

| 行為            |        可獲得經驗值 |
| ------------- | ------------: |
| 發表桌遊攻略文章      |         30 XP |
| 發表活動心得文章      |         20 XP |
| 發表開箱分享文章      |         20 XP |
| 發表規則討論文章      |         12 XP |
| 發表揪團交流文章      |          0 XP |
| 按讚他人的社員論壇文章   |          1 XP |
| 自己的社員論壇文章獲得按讚 | 每 10 讚獲得 1 XP |
| 自己的留言獲得按讚     | 每 10 讚獲得 1 XP |

注意事項：

* 按讚自己的文章不會獲得 1 XP。
* 只有「按讚社員論壇文章」會讓按讚者獲得 1 XP。
* 按讚留言不會讓按讚者獲得 XP。
* 文章或留言被刪除後，相關經驗值也會重新計算。
* 若取消按讚，相關經驗值也可能會重新計算。

---

## 五、等級升級規則

網站等級從 Lv.1 開始。

每一級升到下一級所需的經驗值會逐級增加。

升級所需經驗值公式如下：

```txt
升下一級所需 XP = 30 + (目前等級 - 1) × 15
```

也就是說，等級越高，升級需要的經驗值越多。

## 八、首頁文章

網站首頁會顯示社團最新文章與活動資訊。

首頁文章卡片可能包含：

* 文章標題
* 文章簡介
* 文章圖片
* 瀏覽數
* 留言數
* 按讚數

點選文章卡片即可進入完整文章頁。

---

## 九、活動文章功能

活動文章通常是社團發布的正式內容，例如迎新活動、社團活動、特別企劃等。

進入活動文章後，可以使用以下功能。

### 1. 閱讀文章

可以查看完整活動內容、圖片與說明。

### 2. 按讚文章

點選文章下方的按讚按鈕，可以替文章按讚。

再次點選可取消按讚。

### 3. 查看瀏覽數

文章會顯示瀏覽數，代表文章被閱讀的次數。

### 4. 查看留言數

文章會顯示目前留言數。

### 5. 發表留言

在文章底部留言區輸入內容後，點選送出即可留言。

### 6. 編輯自己的留言

若留言是自己發布的，可以點選留言旁的編輯按鈕。

操作方式：

1. 點選自己的留言旁的「編輯」
2. 修改留言內容
3. 點選儲存

### 7. 刪除自己的留言

若留言是自己發布的，可以點選留言旁的刪除按鈕。

操作方式：

1. 點選自己的留言旁的「刪除」
2. 確認是否刪除
3. 點選確認後刪除留言

刪除後無法復原。

### 8. 替留言按讚

每則留言都可以按讚。

點選一次為按讚，再點一次可以取消。

## 十、社員論壇

點選網站選單中的「社員論壇」，即可進入社員論壇頁面。

社員論壇是社員分享文章與交流的地方。

可分享的內容包含：

* 桌遊攻略
* 活動心得
* 規則討論
* 開箱分享
* 揪團交流

每篇文章卡片會顯示：

* 封面圖片
* 文章標題
* 主題名稱
* 作者
* 發文日期
* 文章分類
* 瀏覽數
* 留言數
* 按讚數
* 文章摘要

點選「閱讀全文」可以查看完整文章。

---

## 十一、社員論壇分類篩選

社員論壇上方有分類按鈕。

可以點選：

* 全部
* 桌遊攻略
* 活動心得
* 規則討論
* 開箱分享
* 揪團交流

點選分類後，頁面會只顯示該分類的文章。

例如點選「桌遊攻略」，就只會看到桌遊攻略類文章。

---

## 十二、撰寫社員論壇文章

在社員論壇頁面點選「撰寫貼文」，即可進入文章撰寫頁。

撰寫文章時需要填寫：

* 文章分類
* 文章標題
* 主題名稱
* 封面圖片網址
* 文章摘要
* Markdown 文章內容

完成後點選「送出審核」。

文章送出後會先進入審核狀態，審核通過後才會公開顯示在社員論壇。

---

## 十三、文章送審流程

社員撰寫文章後，流程如下：

```txt
社員撰寫文章
→ 送出審核
→ 文章暫時不公開
→ 審核通過後公開顯示在社員論壇
```

送出後，系統會顯示文章已送出審核。

在文章尚未通過審核前，一般社員不會在社員論壇列表中看到該篇文章。

---

## 十四、文章分類說明

撰寫文章時需要選擇分類。

### 桌遊攻略

適合撰寫遊戲教學、策略分析、角色玩法、技巧整理等內容。

範例：

* 阿瓦隆新手攻略
* 璀璨寶石購牌策略
* 卡坦島資源交換技巧

### 活動心得

適合分享參加社團活動後的感想與回顧。

範例：

* 迎新活動心得
* 城市尋寶活動回顧
* 桌遊聚會心得分享

### 規則討論

適合針對規則細節、爭議判定、不同版本玩法進行討論。

範例：

* 這個行動是否符合規則？
* 不同玩家數的規則差異
* 擴充規則怎麼判定？

### 開箱分享

適合分享新桌遊、桌遊配件、卡牌內容物、收藏品等。

範例：

* 新遊戲開箱
* 卡牌質感分享
* 桌遊配件介紹

### 揪團交流

適合用來發起聚會、約玩或尋找同好。

範例：

* 本週五有人想玩阿瓦隆嗎？
* 想揪一場策略桌遊
* 徵人一起玩陣營遊戲

---

## 十五、撰寫 Markdown 內容

社員論壇文章使用 Markdown 撰寫。

常用格式如下。

### 副標題

```md
## 副標題1
### 副標題2
```

### 粗體

```md
**這是粗體文字**
```

### 項目符號

```md
- 第一點
- 第二點
- 第三點
```

### 插入圖片

```md
![圖片說明](圖片網址)
```

### 插入連結

```md
[連結文字](網址)
```

### 螢光標記

```html
<mark>這是重點文字</mark>
```

### 調整字體大小

```html
<span style="font-size: 20px;">這段文字會變成 20px</span>
```

---

## 十六、使用 Markdown 工具列

撰寫文章時，內容欄上方會有 Markdown 工具列。

工具列功能包含：

* 副標題1
* 副標題2
* 加粗
* 螢光
* 字體大小
* 項目符號
* 新增圖片
* 新增連結

使用方式：

1. 先反白想套用格式的文字
2. 點選工具列上的功能
3. 系統會自動加入對應格式

例如反白「阿瓦隆詳細規則」，再點選「副標題1」，文字會變成：

```md
## 阿瓦隆詳細規則
```

---

## 十七、插入圖片

目前社員論壇文章使用圖片網址，不直接上傳圖片檔。

建議先將圖片上傳至外部圖床，再將圖片網址貼到文章中。

可使用的圖片格式通常包含：

* JPG
* PNG
* WEBP

圖片語法：

```md
![圖片說明](https://example.com/image.jpg)
```

注意事項：

* 圖片網址需能公開瀏覽
* 建議使用圖片直接連結
* 不建議使用搜尋結果頁網址
* 不建議使用需要登入才能看到的圖片
* 若圖片無法顯示，可能是該網站不允許外部引用

---

## 十八、插入連結

文章可以插入外部連結。

語法如下：

```md
[連結文字](https://example.com)
```

例如：

```md
[官方規則說明](https://example.com)
```

---

## 十九、預覽文章

撰寫文章時，可以點選「預覽」。

預覽功能會將 Markdown 內容轉換成接近正式文章的顯示效果。

發布前建議先預覽一次，確認：

* 圖片是否正常顯示
* 標題層級是否正確
* 文字段落是否清楚
* 連結是否正確
* 字體大小是否合適
* 內容是否有錯字

---

## 二十、查看自己的貼文

在社員論壇頁面可點選「我的貼文」。

進入後可以查看自己曾經投稿或發布的文章。

依照文章狀態，可能會看到：

* 審核中的文章
* 已公開的文章
* 需要修改或未通過的文章

若文章尚未公開，請等待審核結果。

---

## 二十一、編輯自己的社員論壇文章

如果文章是自己發布或投稿的，在可編輯狀態下可以進入編輯頁修改內容。

操作方式：

1. 進入文章頁或我的貼文頁
2. 點選「編輯文章」
3. 修改文章內容
4. 點選儲存修改

若文章仍需審核，修改後可能需要重新等待審核。

---

## 二十二、刪除自己的社員論壇文章

如果文章是自己發布的，可以刪除自己的文章。

操作方式：

1. 找到自己的文章
2. 點選「刪除文章」
3. 確認是否刪除
4. 點選確認後刪除文章

文章刪除後無法復原。

文章刪除後，該文章帶來的經驗值也可能重新計算。

---

## 二十三、社員論壇文章按讚

進入社員論壇文章頁後，可以替文章按讚。

再次點選可以取消按讚。

文章按讚數會顯示在：

* 社員論壇列表
* 文章詳細頁
* 作者經驗值計算中

按讚文章也會影響經驗值：

* 按讚他人的社員論壇文章，可獲得 1 XP。
* 按讚自己的文章，不會獲得 XP。
* 自己的文章每獲得 10 個讚，可額外獲得 1 XP。
* 若取消按讚，相關經驗值也可能會重新計算。

---

## 二十四、社員論壇文章留言

社員論壇文章底部有留言區。

可使用功能包含：

* 發表留言
* 編輯自己的留言
* 刪除自己的留言
* 替留言按讚

留言也會顯示作者的社員 ID。

---

## 二十五、留言按讚與經驗值

每則留言都可以被按讚。

留言獲得按讚後，會計入留言作者的經驗值。

每 10 個留言讚可讓留言作者增加 1 XP。

注意事項：

* 按讚留言本身不會讓按讚者獲得 XP。
* 留言被刪除後，該留言帶來的經驗值也會重新計算。
* 若取消留言按讚，相關經驗值也可能會重新計算。

---

## 二十六、電子報

點選網站選單中的「電子報」，可以進入電子報列表。

在電子報列表中，可以選擇不同月份的電子報。

點選月份後會進入電子報閱讀頁。

電子報閱讀頁支援：

* 電腦版雙頁閱讀
* 手機版單頁閱讀
* 上一頁 / 下一頁切換
* 開啟 PDF 原檔
* 返回電子報列表

如果想看原始 PDF，可以點選「開啟 PDF 原檔」。

---

## 二十七、登出網站

若要登出網站，可以在左側會員資訊區點選「登出」。

登出後將回到登入狀態外的頁面。

若要再次使用留言、按讚、發文、查看等級等功能，需要重新登入。

## 二十八、使用建議

為了讓社員論壇更好閱讀，建議發文時注意以下事項：

* 標題清楚，讓大家一眼看懂主題
* 摘要簡短說明文章重點
* 內容盡量分段
* 善用副標題
* 圖片請使用可公開瀏覽的直接網址
* 若是攻略文章，建議寫出適合新手或進階玩家
* 若是活動心得，可以加入照片、感想與印象深刻的片段
* 若是揪團交流，請寫清楚時間、遊戲、需要人數與地點

## 二十九、常見問題

### Q1：為什麼我送出文章後，社員論壇沒有看到？

因為社員論壇文章需要先經過審核。
送出後文章會先進入審核狀態，通過後才會公開顯示。

### Q2：為什麼我的經驗值沒有立刻增加？

經驗值會依照目前文章、留言與按讚狀態計算。
如果文章尚未公開，或資料尚未更新，顯示可能需要等待一段時間或重新整理頁面。

### Q3：圖片為什麼顯示不出來？

可能原因包含：

* 圖片網址不是直接連結
* 圖片需要登入才能查看
* 圖片網站不允許外部引用
* 圖片網址格式錯誤

建議使用可公開瀏覽的圖片直連網址。

### Q4：我可以修改自己的留言嗎？

可以。
自己發布的留言可以編輯或刪除。

### Q5：我可以取消文章按讚嗎？

可以。
已按讚的文章再次點選按讚按鈕即可取消。
