# 守夜人桌遊社網站操作手冊

第一次登入網站不知道從哪裡開始嗎？
這篇操作手冊會帶大家快速認識守夜人桌遊社網站目前的功能，包含登入方式、社員 ID、社員論壇、活動文章留言、電子報閱讀與等級系統。

## 一、登入帳號與初始密碼

本網站目前僅開放守夜人桌遊社社員登入使用。

大家的登入帳號是：

> 進入社團時登記使用的 Email 信箱

初始密碼暫時統一為：

```txt
00000000
```

首次登入後，如果想要更改密碼，可以在登入頁面點選「忘記密碼」，系統會寄出修改密碼信件。

請特別注意：
目前忘記密碼寄出的信件，大多會被歸類到「垃圾郵件」或「垃圾信件」中。如果收件匣沒有看到，請先到垃圾郵件資料夾找一下。

## 二、登入後可以使用哪些功能？

登入後，網站會開放下列功能：

* 查看社團活動文章
* 在活動文章下方留言
* 幫活動文章與留言按讚
* 查看文章瀏覽數、按讚數與留言數
* 修改自己的社員 ID
* 查看自己的等級與經驗值
* 使用社員論壇
* 撰寫社員論壇文章
* 編輯或刪除自己的論壇文章
* 回報有疑慮的文章
* 閱讀電子報

若尚未登入，網站會自動引導至登入頁面。

## 三、社員 ID 設定

登入後，網站左側欄會顯示你的社員資料，包含：

* 社員 ID
* 目前等級
* 目前經驗值
* 經驗值進度條
* 登出按鈕

如果第一次登入時顯示的名稱不是你想使用的暱稱，可以點選「更改 ID」自行修改。

社員 ID 會顯示在：

* 活動文章留言
* 社員論壇文章作者
* 社員論壇留言
* 文章疑慮回報資料

建議使用大家認得出你的暱稱，會比較方便社員之間互動。

## 四、首頁最新文章

首頁會顯示社團最新文章與活動紀錄。

在「最新文章」區塊，每篇文章卡片會顯示：

* 文章封面
* 文章標題
* 文章簡介
* 按讚數
* 瀏覽數
* 留言數

點擊文章卡片後，就可以進入完整文章頁面。

## 五、活動文章互動功能

社團活動文章通常是由管理員更新到網站中，例如迎新、城市尋寶、保齡球活動、社員活動紀錄等。

進入文章後，文章底部會有互動區，包含：

* 文章按讚
* 瀏覽數
* 留言數
* 留言區

你可以在文章底下留言，也可以替文章或其他人的留言按讚。

### 留言功能

在留言區輸入內容後，點選「送出留言」即可發表。

每位社員可以編輯或刪除自己的留言。
刪除留言時，系統會跳出確認視窗，避免誤刪。

### 按讚功能

文章與留言都可以按讚。
再次點擊已按讚的按鈕，會取消按讚。

## 六、社員論壇功能

網站中有「社員論壇」頁面，提供社員自由發表內容。

目前文章分類包含：

* 桌遊攻略
* 活動心得
* 規則討論
* 開箱分享
* 揪團交流

社員論壇首頁會顯示目前已發布的文章，每篇文章會包含：

* 封面圖片
* 文章標題
* 文章分類
* 主題名稱
* 作者
* 發布日期
* 文章摘要
* 按讚數
* 瀏覽數
* 留言數

點擊文章即可進入完整內容。

## 七、撰寫社員論壇文章

在「社員論壇」頁面中，點選「撰寫貼文」即可開始投稿。

撰寫文章時需要填寫：

* 文章分類
* 文章標題
* 主題名稱
* 封面圖片網址
* 文章摘要
* Markdown 文章內容

### 封面圖片

目前封面圖片採用「圖片網址」方式。
請先將圖片上傳到可公開瀏覽的圖床或其他圖片空間，再把圖片網址貼到欄位中。

請注意：
不是每個網頁網址都能直接當圖片使用。圖片網址通常要能直接開啟圖片本身，常見結尾會是：

```txt
.jpg
.png
.webp
```

如果圖片預覽失敗，代表該網址可能不是直接圖片連結，或圖片平台不允許外部網站讀取。

## 八、Markdown 編輯工具列

撰寫文章與編輯文章時，網站提供簡易 Markdown 工具列。

目前支援：

* 副標題 1
* 副標題 2
* 加粗
* 螢光標記
* 字體大小
* 項目符號
* 新增圖片
* 新增連結

### 副標題

選取文字後點選副標題按鈕，會自動變成 Markdown 標題格式。

例如：

```md
## 阿瓦隆詳細規則
```

### 加粗

選取文字後點選「加粗」，會變成：

```md
**重要文字**
```

### 螢光標記

選取文字後點選「螢光」，會變成：

```html
<mark>重點內容</mark>
```

### 新增圖片

點選「新增圖片」後，會跳出視窗，請輸入：

* 圖片說明文字
* 圖片網址

送出後會自動插入：

```md
![圖片說明](圖片網址)
```

### 新增連結

點選「新增連結」後，輸入連結文字與網址，就會插入：

```md
[連結文字](網址)
```

## 九、編輯與刪除文章

社員可以編輯或刪除自己發布的社員論壇文章。

進入自己的文章頁後，會看到：

* 編輯文章
* 刪除文章

點擊「編輯文章」後，可以回到文章編輯頁修改內容。

點擊「刪除文章」後，系統會跳出確認視窗。確認後，文章會被刪除，且無法復原。

## 十、文章有疑慮回報功能

如果看到社員論壇文章有疑慮，可以在文章頁點選「文章有疑慮」。

點擊後會跳出視窗，請輸入你覺得有疑慮的地方，例如：

* 內容不適當
* 資訊有誤
* 圖片來源有疑慮
* 與社團無關
* 其他需要管理員協助確認的狀況

送出後，管理員會在後台看到該筆回報。

若管理員確認文章確實有問題，可以直接刪除文章；若文章沒有問題，管理員可以將回報標記為已處理。

## 十一、管理員功能

管理員登入後，左側列表會額外出現「審核文章」。

管理員可以：

* 查看被回報有疑慮的文章
* 查看疑慮原因
* 進入文章確認內容
* 刪除有問題的文章
* 將回報標記為已處理

另外，管理員進入任何社員論壇文章時，也會開啟管理員權限，可以：

* 編輯任何社員的文章
* 刪除任何社員的文章

管理員等級固定為 Lv.9999，不會累積經驗值。

## 十二、電子報閱讀

網站左側列表中有「電子報」入口。

進入電子報頁面後，可以選擇不同月份的電子報。點選月份後，就會進入該期電子報閱讀頁。

目前電子報閱讀支援：

* 電腦版雙頁閱讀
* 手機版單頁閱讀
* 上一頁 / 下一頁
* 開啟 PDF 原檔

如果覺得頁面太小，也可以使用瀏覽器縮放功能查看。

## 十三、社員等級與經驗值系統

網站有社員等級系統，鼓勵大家多分享桌遊內容與社團心得。

每位社員初始等級為 Lv.1。

左側社員資訊會顯示：

* 目前等級
* 目前經驗值
* 距離下一級所需經驗值
* 經驗值進度條
* 經驗值來源

### 經驗值來源

不同類型的社員論壇文章會提供不同經驗值：

| 文章分類 |   經驗值 |
| ---- | ----: |
| 桌遊攻略 | 30 XP |
| 活動心得 | 20 XP |
| 開箱分享 | 20 XP |
| 規則討論 | 12 XP |
| 揪團交流 |  0 XP |

按讚也會提供少量經驗值：

| 來源   |           經驗值 |
| ---- | ------------: |
| 文章按讚 | 每 10 讚 = 1 XP |
| 留言按讚 | 每 10 讚 = 1 XP |

按讚經驗值主要是額外加分，主要升級來源仍然是發表有內容的文章。

### 刪除文章後經驗值會收回

經驗值是依照目前網站上仍存在的文章與留言即時計算。

如果文章被自己刪除，或被管理員刪除，該文章帶來的經驗值就會自動消失。

也就是說：

* 刪除文章後，該文章的發文 XP 會被收回
* 該文章獲得的文章讚 XP 也會被收回
* 留言若不再存在於有效文章中，也不會繼續計入留言讚 XP

### 等級上限

目前等級上限為：

```txt
Lv.9999
```

管理員帳號固定為 Lv.9999。
Lv.9999 狀態下，不會再因發文或按讚獲得經驗值。

## 十四、常見問題

### Q1：我登入不了網站怎麼辦？

請確認帳號是否為加入社團時登記的 Email。
初始密碼為：

```txt
00000000
```

如果仍無法登入，可以使用「忘記密碼」重新設定。

### Q2：忘記密碼信件沒收到怎麼辦？

請先到垃圾郵件資料夾查看。
目前重設密碼信件常會被歸類到垃圾郵件，需要自行找一下。

### Q3：我可以改自己的社員 ID 嗎？

可以。登入後，在左側社員資訊區點選「更改 ID」即可修改。

### Q4：我可以刪除自己的文章嗎？

可以。進入自己的社員論壇文章後，會看到「刪除文章」按鈕。

### Q5：我可以刪除自己的留言嗎？

可以。自己的留言旁邊會顯示「編輯」與「刪除」按鈕。

### Q6：為什麼我貼的圖片沒有顯示？

請確認圖片網址是可以公開瀏覽的直接圖片連結。
如果只是一般網頁網址，可能無法作為圖片顯示。

### Q7：為什麼我刪掉文章後等級下降了？

因為經驗值是依照目前存在的文章與互動即時計算。
文章刪除後，原本由該文章帶來的經驗值會被收回。

願每一次開局，都能留下值得回味的故事。
